# 자주 묻는 질문 (FAQ)

## 비밀번호를 잊어버렸어요

로그인 화면에서 "비밀번호 찾기"를 누르면 가입한 이메일로 재설정 링크가 발송된다. 링크는 발송 후 30분간 유효하다.

## 환불 정책은 어떻게 되나요

결제일로부터 7일 이내, 서비스를 거의 사용하지 않은 경우 전액 환불이 가능하다. 7일이 지났거나 서비스를 이용한 흔적이 있으면 환불이 제한될 수 있다. 환불 요청은 고객센터 채팅으로 접수한다.

## 계정을 삭제하고 싶어요

설정 > 계정 > 계정 삭제 메뉴에서 신청할 수 있다. 삭제 신청 후 14일의 유예 기간이 있으며, 이 기간 동안 로그인하면 삭제가 취소된다. 14일이 지나면 모든 데이터가 영구적으로 삭제된다.

## API 요청 제한(Rate Limit)은 어떻게 되나요

플랜별로 분당 요청 수가 다르다. 무료 플랜은 분당 10건, 스탠다드 플랜은 분당 60건, 프로 플랜은 분당 300건까지 허용된다. 초과 시 429 응답을 받는다.
