# 서울 경기장 방문 가이드 (잠실·고척)

## 잠실야구장
- 도시철도 2호선 종합운동장역(또는 9호선 종합운동장역)에서 가깝다. 경기 전후에는 역이 매우 혼잡하니 한 정거장 먼저 내리거나 걸어서 이동하는 것도 방법이다.
- 인근에 롯데월드타워 전망대, 한강공원 같은 관광지가 있어 경기 전후 일정으로 묶기 좋다.
- 경기 종료 직후에는 택시 호출이 어렵다. 귀가 시각에 여유를 둔다.

## 고척스카이돔
- 도시철도 1호선 구일역이 가장 가깝다. 돔구장이라 우천 취소 걱정이 적지만, 실내 온도와 반입 가능 물품은 구장 안내를 확인한다.
- 주변에 식당이 많지 않으니 식사는 경기 전에 해결하거나 구장 안 식음료를 이용한다.

## 서울에서 여행할 때
- 지하철 중심으로 동선을 짜면 환승 시간이 늘어나므로, 하루에 방문하는 권역을 한두 곳으로 줄인다.
- 정확한 소요 시간은 지도/대중교통 앱에서 출발 직전에 확인한다. 이 서비스는 경로 API를 쓰지 않는다.
